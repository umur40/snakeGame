Zorluk Seviyeleri: Kolay, Normal, Zor ve Çok Zor seçenekleri

Yüksek Skor Kaydı: LocalStorage kullanarak en yüksek skoru saklar

Farklı Yem Türleri:

Normal yem (1 puan)

Turuncu yem (3 puan)

Cyan yem (5 puan + hız artışı)

Mor yem (-2 puan)

Görsel Efektler:

Yem yendiğinde patlama efekti

Yılan başında gözler

Game over animasyonu

Mobil Desteği:

Dokunmatik kontroller

Ekran boyutuna uyum

Diğer Özellikler:

Oyun duraklatma

Başlangıç ekranı

Yılan vücudu için degrade renkler

Responsive tasarım

Oyunu başlatmak için yön tuşlarını kullanabilir veya "Başlat" butonuna tıklayabilirsiniz. Mobil cihazlarda ekrandaki düğmeleri kullanabilirsiniz
